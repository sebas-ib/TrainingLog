# TrainingLog

TrainingLog is an iOS workout tracking app built with SwiftUI and SwiftData.

## Features

* Create and manage workout sessions
* Log exercises, sets, reps, and weight
* Track workout history by day
* View training volume by muscle group
* Support for different weight units
* Edit and delete workouts
* Workout summaries and consistency tracking

## Tech Stack

* Swift
* SwiftUI
* SwiftData
* Xcode

## Project Structure

```text
TrainingLog/
├── Models/
├── Assets/
├── Views/
└── Support/
```

## Requirements

* iOS 18+
* Xcode 16+
* Swift 6+

## Running Locally

Clone the repository:

```bash
git clone https://github.com/sebas-ib/TrainingLog.git
```

Open the project in Xcode:

```bash
cd TrainingLog
open TrainingLog.xcodeproj
```

Select an iOS simulator or connected device and run the project.
